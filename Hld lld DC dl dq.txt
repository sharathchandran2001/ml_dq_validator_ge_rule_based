1. High-Level Design (HLD)
​The HLD focuses on the "What" and the "Where"—defining the major components and the infrastructure boundaries.
​Component Overview
​External Clients: UI (Next.js), Postman, or upstream CI/CD pipelines.
​Security Layer: Azure Entra ID (App Registrations) providing OAuth2 tokens.
​Orchestration (FastAPI): Hosted on Azure Kubernetes Service (AKS). Manages state and background jobs.
​Compute Engine (PySpark): Ephemeral Spark executors running in AKS, scaling horizontally.
​Persistence (MS SQL): Centralized database for transaction history, job status, and metrics.
​Secrets Management: Azure Key Vault storing JDBC strings and credentials.
​Validation Logic: Great Expectations (GX) integrated into the Spark driver.
​The System Flow
​Request: User sends a validation request with source metadata.
​Auth: FastAPI validates the JWT via Azure Entra ID.
​Initiate: FastAPI logs a PENDING transaction in MS SQL and retrieves DB secrets from Key Vault.
​Execute: A background task triggers the PySpark job.
​Process: The Adapter Factory reads data → GX validates it → Results are parsed.
​Finalize: The final status and summary metrics are updated in MS SQL.

Column Type Description
TransactionID GUID (PK) Unique identifier generated by FastAPI.
UserID String The user/system that triggered the job.
Status Enum Pending, Processing, Completed, Failed.
SourceType String MSSQL, Parquet, Delta, etc.
SuccessPercent Decimal Percentage of GX expectations that passed.
FailedRules Integer Count of failed data quality rules.
LogLink String URL to the detailed GX JSON report in Blob Storage.
CreatedAt DateTime Timestamp of request.
